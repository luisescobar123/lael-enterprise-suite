# LAEL Enterprise Suite (demo front-end)

Propiedad intelectual de Luis Ángel Escobar Leiva. Uso exclusivo para clientes autorizados.

## Abrir en Visual Studio Code
1. Descomprime el ZIP y abre la carpeta en VS Code.
2. Instala "Live Server", clic derecho en index.html > "Open with Live Server" (o abre index.html en el navegador).

## Contenido
- index.html: landing, facturación, equipo, gestión (Gantt, asistencia, desempeño, reportes), IA, seguridad (MFA y auditoría simulados), arquitectura, integraciones, documentación.
- docs/: manual de usuario, guía técnica, API, seguridad y cumplimiento, contrato de licencia (plantilla).

Es una demo visual: no hay backend ni integraciones reales todavía.
